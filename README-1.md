## 🎯 About the Project

**IronForge** is a premium gym and fitness website developed as part of the **Fusiotech Frontend Web Developer Internship** (Project Development Phase). The goal was to build a production-quality, fully responsive fitness website that promotes membership plans, showcases training programs, and provides a seamless user experience across all devices.

The design philosophy focuses on a **luxury dark aesthetic** — black and gold palette, bold typography, and smooth micro-interactions — giving it a high-end gym brand feel.

---

## ✨ Features

| Section | Description |
|---|---|
| 🦸 **Hero Section** | Full-viewport landing with headline, stats counter, and CTA buttons |
| 💪 **Workout Programs** | 6 programs with hover animations and difficulty tags |
| 👨‍🏫 **Trainers** | 4 certified trainers with experience stats and specializations |
| 💳 **Membership Plans** | 3-tier pricing (Starter / Pro / Elite) with feature comparison |
| 📊 **BMI Calculator** | Metric & Imperial support with color-coded result bar and fitness tips |
| 🌟 **Testimonials** | Member success stories with star ratings |
| 📬 **Contact Form** | Validated form with success feedback |
| 📱 **Fully Responsive** | Optimized for mobile, tablet, and desktop |

### Bonus Features
- Fixed navbar with glassmorphism blur on scroll
- Scroll-reveal animations via Intersection Observer API
- Mobile hamburger menu
- Custom scrollbar styling
- CSS Grid + Flexbox layout throughout
- Google Fonts integration (Bebas Neue + Inter + Space Grotesk)

---

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** — BMI logic, form validation, scroll effects
- **Google Fonts** — Bebas Neue, Inter, Space Grotesk
- **Netlify** — Deployment

> ⚡ Zero frameworks. Zero dependencies. Pure web fundamentals.

## 🚀 Getting Started

### Prerequisites
Just a modern web browser. No installs needed.

### Run Locally

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/ironforge-gym-website.git

# Navigate into the project
cd ironforge-gym-website

# Open in browser
open index.html
# or just double-click index.html
```

### Deploy on Netlify
1. Drag and drop the project folder on [netlify.com/drop](https://app.netlify.com/drop)
2. Get your live link instantly ✅
