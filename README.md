# Gym & Fitness Website

## Project Overview
This is a responsive Gym & Fitness Website developed using HTML, CSS, and JavaScript as part of my internship project. The website is designed to help gyms showcase their services, membership plans, trainers, and fitness programs in a modern and user-friendly way.

## Features
- Responsive design for mobile, tablet, and desktop
- Hero section with call-to-action buttons
- Workout programs section
- Trainer profiles
- Membership plans
- BMI Calculator
- Testimonials section
- Contact form with validation
- Smooth scrolling and animations

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
